# Maintaining the site

Everything under `BUILD:` markers in `index.html` and `README.md`, plus `papers/`, `publications.bib`,
`feed.xml` and `sitemap.xml`, is generated by `scripts/build.py`. Edit the files in `data/` instead.

| To do this | Edit |
|---|---|
| Add a thesis, report or Zenodo item | `data/publications.json` → `manual` |
| Change how an arXiv paper is shown (short summary, extra links, venue) | `data/publications.json` → `overrides` |
| Hide a paper that is not yours | `data/config.json` → `exclude_arxiv_ids` |
| Add a news item | `data/news.json` |
| Register a new static page in the sitemap | `data/config.json` → `static_pages` |

Pushing changes to `data/` rebuilds the site automatically. Every Monday the
**Publications** workflow checks arXiv and opens a pull request when it finds something new;
merging it publishes the change. You can also run it from the Actions tab.

Local preview:

```sh
python scripts/build.py          # rebuild from data/
python scripts/build.py --fetch  # also query arXiv
python -m http.server            # then open http://localhost:8000
```

For the most reliable matching, link your ORCID in your arXiv account
(arXiv > Account > Link ORCID). The sync reads `arxiv.org/a/<ORCID>` first and
only falls back to a name search.
